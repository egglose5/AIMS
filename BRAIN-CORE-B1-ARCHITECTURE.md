# Ancient Innovations Brain Core — Pass B1

Ancient Innovations owns the Brain. Models, agent runtimes and orchestration frameworks are replaceable components.

- Control App / Arm-owned data remain source of truth.
- Brain permissions are deny-by-default.
- Scout and Show Brain are separate agents governed by the same Brain Core.
- Hermes is the planned autonomous runtime for Scout, but gets no direct database credentials.
- Controlled orchestration is connected through a replaceable adapter; Microsoft Agent Framework is the planned first adapter.
- Reasoning model providers remain replaceable and are not hard-wired in B1.
- Consequential actions such as applications, spending and vendor assignment remain human/business-workflow controlled.
- Every future agent action can be audited through BrainAuditEvents.
