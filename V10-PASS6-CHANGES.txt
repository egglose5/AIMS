Ancient Innovations Control App v10 Pass 6 - Operational Fulfillment Stages

Built from the known-good Pass 5.1 baseline.

Changes:
- Fulfillment now has operational stages: Ready to Pick, Picked, Ready to Pack, Ready to Ship, Shipped, Complete.
- Production remains a separate state. A Needs Production order must be marked Production Complete before it enters Ready to Pick.
- Fulfillment status buttons update the shared record directly.
- Square Show Order legacy status is kept compatible so the existing Show Orders page remains usable.
- Opening Show Orders no longer intentionally pushes a richer fulfillment record backward to an older coarse status.
- No WooCommerce intake, Pirate Ship, automatic stock decision, or label purchasing was added in this pass.
- No database wipe or schema change is required for Pass 6.
