Ancient Innovations Control App v10 Pass 8.7 — Square Catalog Inventory Source of Truth

- Inventory/Barcode setup now loads its master item list directly from the connected Square catalog.
- Every Square item variation is shown, even when no local artwork/process image exists.
- Local front-face images are visual helpers only and no longer decide which items exist in Inventory.
- Square item ID and variation ID are persisted on the local SellableProduct record when a barcode/count is initialized.
- Existing initialized Square-linked products are recognized by Square IDs rather than artwork-folder presence.
- Generic Square items can receive a permanent 5-digit Ancient Innovations barcode and initial on-hand count.
- Notebook Black/Brown variations remain compatible with the existing notebook production/replacement model.
- If Square cannot be loaded, Inventory shows an error instead of silently substituting local artwork folders.
- No fulfillment, customer-order barcode, DYMO page-size, or database schema behavior was removed.

Primary verification case: search Inventory for "Whispering Mill". If it is an active Square catalog item, it must appear even if it has no local image/process folder.
